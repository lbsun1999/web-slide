# Web Slide 公开文档中心

本目录是新版 Web Slide 工作台的公开说明资料，不包含可编辑模板、运行脚本、工作台源码、项目数据或导出文件。

下载或克隆公开仓库后，可在本地打开 `html2ppt-web-slide-docs/index.html` 浏览图文导航；在 GitHub 上请直接使用下列 Markdown 文档。
