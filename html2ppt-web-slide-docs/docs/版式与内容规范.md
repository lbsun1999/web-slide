# 版式与内容规范

## 内容密度

- 页面应丰满但不拥挤，避免大面积无意义留白。
- 内容过少时优先补充证据、条件、解释或结论，也可换用更紧凑版式。
- 页尾总结可以增强页面重点，但普通备注卡不能冒充页尾总结。
- 一个文字板块的列点通常不超过 4 条；超过时应拆分板块或合并内容。

## 字号与层级

- 正文页主标题是页面最高层级，其他强调文字不得超过它。
- 模块题目、子区域题目与正文必须通过字号形成层级，不能只靠加粗。
- 表格通常在 8–14 pt 范围内自适应，图标题建议约 14 pt。
- 标题类文字优先保持单行；确需换行时按语义手动拆分。

## 换行与段落

- 避免末行只剩一两个字，必要时适量改写或按完整语义分行。
- 多句话若拆成“一行一句”更利于阅读，可以主动分行；否则保持自然段。
- 自动换行的段落之间应保留清晰段距，列表前导符与正文保持稳定距离。

## 表格

- 深色底用于顶部表头行，不默认涂深第一列。
- 多级表头可按列族分组，必要时使用竖线区隔。
- 单元格左右至少保留半个字符空间，文字顶端或垂直对齐方式应按表格类型统一。
- 参考文献表采用序号列＋内容列，顶端、左侧对齐，并允许链接和日期符号处合理断行。

## 公式与图文

- 一个公式一个浅色框：深底白字公式标题、公式主体和一句解释。
- 变量用数学斜体，向量／矩阵按学科规范使用粗体，函数名、单位和标点保持正体。
- 并列图片保持实际画面等高；有无图注时都应重新分配空间，不保留无意义图注空槽。
- 多板块尽量边缘平齐，并保持相同的图文垂直间距。
