# 后续功能规划

以下内容属于后续研究与实现方向，当前版本尚未开发，不构成现有功能承诺。实际实现顺序将根据使用反馈、算力条件和文件兼容性评估确定。

## 1. AI 插图与复杂媒体边界：让插图能生成、能替换，也能正确参与排版

建立面向幻灯片的 AI 插图流程，支持生成或导入 SVG、替换已有插图并保留比例与清晰度。进一步研究透明度蒙版、异型 PNG 的有效可见区域识别和遮挡判定，避免系统只按图片外接矩形判断重叠，从而浪费透明区域或产生误报。

可能涉及的内容包括：

- 建立适合科研汇报的插图提示词、尺寸、配色和风格约束；
- 完善 SVG 上传、预览、重着色、替换和导出流程；
- 为普通图片提供透明度、蒙版、裁剪与背景处理；
- 根据异型 PNG 的真实可见轮廓判断遮挡，而不是只看外接矩形；
- 保持浏览器、PDF 与 PPTX 中的清晰度、比例和透明效果一致。

## 2. 模板库与特殊排版资产：让新主题和新页面可以增量加入

把学校主题、常用页面、特殊排版和环形分布组合整理为可增量安装的模板库。模板不仅保存视觉样式，还应记录页面结构、模块约束和适用内容，支持 PPT 母版预制与复用，同时避免把母版背景误识别为可编辑内容或遮挡对象。

可能涉及的内容包括：

- 为模板定义清单、预览、版本、依赖和兼容范围；
- 把学校主题、党政主题、科研主题与常用特殊页面分层管理；
- 保存环形分布、时间轴、简历、公式、图表等复合模块的结构规则；
- 预制并复用 PPT 母版，同时区分背景装饰与可编辑正文对象；
- 在不修改工作台核心代码的前提下安装、迁移或移除模板资源。

## 3. AI 对话内嵌与算力调度：让内容讨论和页面修改留在同一工作流

研究在工作台内直接完成材料整理、大纲讨论、页面修改和局部重写，使用户不必在对话窗口与编辑器之间反复复制。该能力需要同时解决模型调用权限、隐私、长文档上下文、费用和本地／云端算力选择问题。

可能涉及的内容包括：

- 让 AI 读取当前大纲、页面、备注和选中对象，而不是依赖重复粘贴；
- 对改写、增删和版式建议提供差异预览、确认与撤销；
- 根据任务类型选择不同模型或本地能力，控制延迟和使用成本；
- 对长文稿、图片和历史修改建立可控的上下文与缓存机制；
- 在无网络、无授权或算力不足时提供明确的降级方案。

## 4. Draw.io 框图接口与二次编辑：让框图既能快速生成，也能继续修改

为流程图、系统框图、网络结构和方法路线提供 Draw.io 接口。AI 可以根据材料生成初稿，用户继续在 Draw.io 中编辑，再以 SVG／PNG 或可回写的数据形式嵌入幻灯片。目标是兼顾画面清晰度和后续可修改性，不把框图永久固化为不可编辑截图。

可能涉及的内容包括：

- 调用 Draw.io 相关能力生成流程图、架构图、网络图和方法路线；
- 同时保留 `.drawio` 源文件与用于展示的 SVG／PNG；
- 从幻灯片重新打开源图编辑，并把修改结果回写到原位置；
- 同步画布尺寸、主题颜色、字体和线条规范；
- 在导出 PPTX 时评估整体图片、分组形状或混合方案的可编辑性。

## 5. 高级图表与可编辑数据缓存：让数据更新不必重新作图

内置常用科研图表样式和绘图脚本，让用户导入 Excel／CSV 后在网页中生成、调整和预览图表。除了输出图片，还应缓存能够再次修改的数据、配置和绘图文件，保证更换数据、颜色、坐标轴或标注时不必从头绘制。

可能涉及的内容包括：

- 内置适合科研汇报的折线图、柱状图、散点图、热力图等样式；
- 导入 Excel／CSV 后完成字段识别、数据校验和图表映射；
- 在线调整颜色、坐标轴、图例、误差线、标注和尺寸；
- 缓存源数据、绘图参数和脚本，使图表能够再次打开修改；
- 研究在 PPTX 中保留图表可编辑性的导出方式，并处理字体与色彩差异。
