# 大纲格式说明

大纲可直接输入、粘贴，或从 `.md`／`.txt` 文件读取。

```markdown
# 汇报总标题

## 01 研究背景与意义

### 问题背景
第一段普通正文作为页首句，可留空。

第二段普通正文作为页尾总结，可留空。

> 引用块作为该页备注，可记录讲解提示、来源和制作要求。

### 研究现状

## 02 研究方法

### 模型与目标函数

## 附录

### 参考文献
```

## 映射规则

- `#`：文档总标题；
- `##`：章节标题；
- `###`：页面标题；
- 第一个正文段落：页首句；
- 空一行后的第二个正文段落：页尾总结；
- `>` 引用块：页面备注；
- 最后一章可明确勾选为附录，不必进入正式目录。

空字段不应覆盖旧页面已有内容。改动大纲后仍须核对页面正文、图片、公式与新标题是否匹配，不能只改页眉。
