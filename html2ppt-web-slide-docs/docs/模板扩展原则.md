# 模板扩展原则

模板扩展应采用增量式管理：每套学校／主题模板拥有自己的身份、配色、标志、图片与示例内容，但共享工作台能力。

## 可以复用

- 页面结构与模块类型；
- 字号、边距、对齐和内容密度规则；
- 公式、表格、图片、时间轴、参考文献和作者简介等页型；
- 放映、备注、教学与导出流程。

## 必须重新核对

- 学校中英文名称、校训和办学理念；
- 官方标志、标准色和素材使用权限；
- 校史、校区、学院和校园图片；
- 主题色下的深底白字、浅底深字和辅助色对比度；
- 示例内容是否符合目标学校和汇报语境。

新增模板不应要求复制一套编辑器或修改其他模板。学校素材和第三方图片仍受各自权利人的许可限制。
