# AI 协作工作流

## 制作前先确认大纲

建议先用下列结构与 AI 沟通：

```markdown
# 幻灯片总标题

## 01 章节标题

### 页面标题
页面首句或本页核心任务。

页面底部需要强调的总结句。

> 本页备注、来源线索或交给 AI 的制作要求。
```

确定章、页关系后，再在现有模板上加工，能显著减少返工。

## AI 负责

- 从材料中提取主线、证据和结论；
- 提议章节顺序和逐页标题；
- 选择合适的表格、公式、图文或时间轴版式；
- 初步控制内容密度、标题层级和页面一致性；
- 根据用户反馈继续修改，而不是擅自推翻已确认内容。

## 用户负责

- 确认事实、数据、引用、图片版权和学校信息；
- 判断内容取舍、表达语气和汇报重点；
- 审核页面是否真正适合现场讲解；
- 检查导出的 PDF／PPTX，并完成最终签发。

## 迭代方式

用户应尽量指出具体页面、对象和问题，例如“第 7 页右侧留白过大”“表头应为深底白字”“这段末行只有两个字”。AI 修改后应重新检查相邻页面和共性规则，避免只修一个局部。
