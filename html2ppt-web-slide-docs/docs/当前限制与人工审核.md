# 当前限制与人工审核

新版工作台仍处于私有测试阶段，功能、界面和数据结构可能继续调整。

## 已知边界

- 不同浏览器和屏幕缩放比例可能造成细微视觉差异；
- 不同 PowerPoint 环境可能替换字体或改变局部换行；
- 复杂公式、超长链接和特殊表格仍可能需要人工微调；
- 自动边界检查能发现溢出和遮挡，但不能判断内容是否真实、得体或足够有说服力。

## 交付前检查

1. 标题、章节编号和目录页码一致；
2. 无末行孤字、意外自动换行、遮挡或超出安全区；
3. 表格表头、单位、箭头、均值与标准差格式正确；
4. 公式变量、向量、单位和标点字体规范；
5. 图片清晰、比例合理、图注和来源完整；
6. 参考文献格式、链接和访问日期已核对；
7. 页尾总结、页脚和页码在导出文件中保持单行；
8. 使用真实放映设备试讲，并检查演讲者备注。

AI 与自动测试只能缩小人工检查范围，不能替代最终审核。
